# Telegram Bio Link Guard & Auto Delete Bot

GitHub repository template for hosting Telegram Bio Protection and Auto Delete Bot.

## Deployment Setup (Environment Variables)

Set the following environment variables on your hosting platform (Koyeb, Render, Railway, Heroku, etc.):

- `API_ID` : Telegram API ID (from my.telegram.org)
- `API_HASH` : Telegram API Hash (from my.telegram.org)
- `BOT_TOKEN` : Bot Token from @BotFather
- `OWNER_ID` : Your Telegram User ID
